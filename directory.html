Mail advice

What makes a strong request?

01

Keep it neat

Use a clean card, clear return address, and a simple note that is easy to read.

02

Include the basics

Always add your name, address, and a polite request or offer to send a self-addressed envelope.

03

Be patient

Response windows vary by signer, so track contact history and give every request time.

04

Stay respectful

Professional, friendly requests are more likely to stand out in a crowded mail room.
